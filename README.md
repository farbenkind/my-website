# audiovisual-lab

Ein kleines audiovisuelles Projekt mit einer donation-basierten, source-available
Nutzungslogik.

## Ziel

Diese App soll als kreatives Werkzeug für audiovisuelle Experimente dienen. Die
Idee, das Produkt und die kreative Ausrichtung bleiben Eigentum des Projektinhabers.

## Nutzungsmodell

- kostenlos nutzbar für persönliche und experimentelle Nutzung
- freiwillige Spenden willkommen
- bestimmte Funktionen können ohne Spende eingeschränkt sein
- keine freie Open-Source-Nutzung
- keine Kopie, Weiterverbreitung oder Wiederverwendung ohne Zustimmung
